# QuantLens · 投研工坊

## 1. 简要介绍

QuantLens（投研工坊）是面向 A 股的日频量化研究工具，提供数据同步、条件选股、因子评估、策略回测和账户持仓功能，也支持用 AI 辅助研究因子和解读结果。

项目涉及的大数据处理技术有 Hadoop HDFS、YARN、Hive、Spark SQL、Spark MLlib 和 HBase。历史数据存放在 HDFS，Hive 管理分层表，Spark 在 YARN 上完成清洗、因子计算和模型训练，HBase 提供个股及因子快照查询。处理结果以 Parquet 格式保存，网页通过 DuckDB 查询本地发布结果。

## 2. 安装方式

运行环境：

- Linux、Python 3.12、Docker 和 Docker Compose 插件。
- 至少 16 GB 内存、8 vCPU、20 GB 可用磁盘；首次构建镜像时，还需为下载文件和构建缓存预留空间。
- 下载 CSMAR 数据需要相应访问权限，以及校园网或校园 VPN 环境。

进入项目根目录，创建 Python 虚拟环境并安装依赖：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

构建大数据集群镜像：

```bash
bash docker/cluster.sh build
```

Python 依赖版本记录在 `requirements.txt`，集群版本记录在 `docker/versions.env`。当前使用 Hadoop 3.3.6、Hive 3.1.3、Spark 4.0.1 和 HBase 2.2.7。镜像内分别为 Hadoop、Hive、HBase 配置 JDK 8，为 Spark 配置 JDK 17。

## 3. 启动方式

以下命令均在项目根目录执行。

激活虚拟环境，启动服务：

```bash
source .venv/bin/activate
python main.py
```

`python main.py` 会先启动网页与后端 API 并打开浏览器，再在后台启动 HDFS/YARN、Hive、HBase、Spark 和训练服务。默认地址为 <http://127.0.0.1:8610>。启动进度和错误可在顶栏及「设置 → 集群」查看，控制台不输出启动提示。再次运行命令会先正常退出同一项目、同一端口的旧网页服务，再启动新的前后端并打开页面；已打开的页面会检测重启并自动刷新。集群和训练服务仍会在后台检查并补齐。首次启动前需完成上述集群镜像构建，并确保 Docker 已运行。

指定端口时使用：

```bash
python main.py --port 8611
```

首次使用时，在「设置 → 数据同步」中点击「检查更新并同步」。系统按计划下载 CSMAR 数据，完成入库、清洗和页面数据发布。因子计算和模型训练由研究任务单独执行。

## 4. 功能介绍

网页主导航包括工作台、条件选股、因子研究、策略研究、回测结果、账户持仓和设置。因子研究包含因子库、新因子研究和因子实验；策略研究包含策略库、新策略研究和策略实验。回测结果独立展示因子与策略研究产生的回测记录。市场规则在设置中管理。研究助手从顶栏打开，个股档案可通过证券代码进入。

### 4.1 数据同步与分层存储

在「设置 → 数据同步」中查看数据表和更新计划，按需补齐行情、财务、分析师预期、股东持仓和行业分类数据。系统记录接入分区、行数、校验值与数据快照，供后续研究核对来源。

同步保留已有因子、权重和研究结果的日期与版本。更新数据后，可在研究任务中计算因子，再用已有策略生成信号。在「策略研究 → 新策略研究」中与 AI 讨论研究想法，由 AI 整理策略假设和因子组合，再交给本地量化模型训练权重并自动完成选股、回测和报告。

数据按 ODS、DWD、DWS、ADS 四层处理：

| 数据层 | 内容与处理方式 |
| --- | --- |
| ODS 原始层 | 将 staged Parquet 数据按年分区接入 HDFS，由 Hive 管理表结构和分区。 |
| DWD 明细层 | 用 Spark 清洗行情，按实际可见日期对齐财务、预期与行业数据，生成股票池、未来收益标签和质检结果。 |
| DWS 研究层 | 保存 Spark 计算的因子值、评估指标、策略权重、风格簇和算法研究结果。 |
| ADS 应用层 | 保存市场概览、选股、策略信号、目标持仓、回测和归因等页面结果。 |

各层以 Snappy 压缩的 Parquet 文件存储，通过 Hive 分区发布。研究结果带有 `run_id`、因子版本和 `data_snapshot`，用于关联同一次计算的输入与输出。

### 4.2 工作台

工作台展示最新交易日、覆盖证券数、数据覆盖天数、市场平均涨跌和因子评估数量，也能查看市场广度、数据质检、最近研究和待处理任务。

市场统计由 Spark 预先聚合到 ADS，页面通过 DuckDB 读取本地发布结果。

### 4.3 条件选股与个股研究

支持按历史日期、价格、成交额、20 日涨幅、60 日价格位置、净资产收益率、负债率和行业筛选股票。也可以用自然语言描述条件，由模型填写筛选表单，核对后执行。

点击证券代码可查看价格走势、财务指标、分析师预期、机构持仓、因子值和策略信号，并记录关注依据与失效条件。

选股指标由 Spark 在 ADS 中预先生成，财务和预期数据按 DWD 中的实际可见日期对齐。页面行情与选股覆盖最新数据日向前 400 个自然日，完整历史研究使用 DWD、DWS 数据。HBase 保存个股最新行情档案和因子快照，支持按证券、日期点查。

### 4.4 因子研究

因子库管理因子版本、依赖字段、适用范围和评估结果。内置因子涵盖价值、质量、成长、动量、反转、分析师预期及机构持仓等方向；自定义因子使用 `compute(panel)` 接口编写，插件放在 `factors/`，元数据登记在 `config/factors.yaml`。

Spark 按时间窗口分发完整股票横截面，执行因子计算，再按配置完成去极值、标准化和中性化。评估结果包括 Rank IC、ICIR、覆盖率、分组收益、单调性、换手率和因子相关性。

「因子实验」选择一个因子后启动自动进化。候选搜索和复盘只读取固定训练区间；先冻结训练中最好的候选，再比较基线与候选的滚动验证表现。验证失败后结束本次搜索，不把验证结果反馈给下一轮调参。通过开发期门槛后才允许使用锁定测试。开发阶段可以由 Codex 在本地研究脚本中直接提供候选和复盘，无需调用配置模型或新增后端路由。

### 4.5 策略研究与本地量化模型

策略研究按“本地模型配权 → 选股方案 → 样本外回测 → 报告”运行。新策略研究页与新因子研究页采用同一套讨论弹窗、模型选择和对话历史。与 AI 讨论希望选择哪类公司、因子如何互补、预期持有时间和失效条件，点击“开始自动研究”后，AI 从已启用且方向明确的因子中整理可执行方案，自动启动本地模型实验。语言模型负责整理假设和方案，本地线性回归或逻辑回归负责训练数值权重；整个流程无需人工审批。

训练仅使用指定区间内、未来五日收益已在回测开始前成熟的样本。模型系数按绝对值之和归一化，负权重表示反向使用因子；回测期间权重固定，不根据回测结果重新选择模型。选股方案和回测使用相同的评分及组合约束，报告记录权重、因子版本、数据快照、收益、回撤和研究范围。

策略只有“已启用、已停止、研究中”三种状态，与因子采用相同的存储值 `active`、`disabled`、`draft`。任务进度和失败原因单独展示。研究完成后可直接启用，停止后可重新研究。策略实验页采用与因子实验相同的会话表、实验介绍、已完成回测、实验结果和进度布局。每次运行独立保留任务结果，重新实验不会将旧会话替换成最新结果。旧实验接口和旧页面已删除。

训练作业用 Spark SQL 准备数据，数值拟合交给宿主机训练服务，并按时间划分训练期与测试期：

- 线性回归、逻辑回归：拟合多因子组合权重，比较各方法的样本外表现。
- GBT：将梯度提升树预测值注册为 `model_gbt` 因子，接受统一的因子评估。
- KMeans：根据历史市场特征划分股票风格簇，为组合集中度控制提供分组。
- FP-Growth：挖掘高分因子的共现组合，形成待验证候选。
- PCA：生成主成分得分与载荷，比较降维前后的研究表现。

训练服务默认自动检测 NVIDIA CUDA 独立显卡，优先使用 GPU；没有可用显卡、驱动或运行库不支持、显存不足或外接显卡断开时，在独立 CPU 进程中重算当前任务。每次任务重新检测设备，重新接入显卡后后续任务可恢复 GPU。`QUANTLENS_TRAIN_DEVICE=auto` 为默认值，`cuda` 表示优先 GPU 并允许设备故障回退，`cpu` 表示固定 CPU。请求结果记录实际设备、各次尝试与回退原因。

线性回归、逻辑回归、PCA 和 KMeans 在两种设备上使用同一套 PyTorch 算法，树模型统一使用 XGBoost histogram；浮点运算允许微小差异。CPU 重试沿用同一输入和种子，输入错误、模型错误和因果性检查失败直接停止。自定义因子代码仍在受限 CPU 沙箱执行，交易撮合与账户核算仍使用 CPU；GPU 不代表整个研究流程都能加速。

### 4.6 策略配置与回测

在「策略研究 → 策略库」查看因子权重、目标选股方案、样本外指标和报告；点击“查看完整回测结果”可进入独立回测页，查看净值、成交、持仓、费用及收益归因。研究完成后点击“启用”即可用于持仓建议。市场规则在「设置 → 市场规则」查看。

系统会注册“通用研究（包含科创板）”默认模拟账户，初始资金为 100 万元。新建回测使用所选账户当前可投资净值和科创板权限；未开通权限的账户会在选股阶段排除科创板。回测结果保存当时的账户名称、资金和权限。历史模拟从现金开始，当前持仓只用于计算资金规模。

当前回测协议采用次日收盘成交、T+1、市场规则费用和 10 bp 滑点，以 Calmar 为主要目标，同时约束最大回撤与年化单边换手。交易处理考虑停牌、涨跌停、整手要求和现金余额。

因子和策略回测均由模型在回测前选择收益基准与整体市场参照，同一研究的候选沿用冻结方案。收益基准支持同风格簇等权、股票池等权、流通市值加权、同行业等权、全收益指数、混合基准和现金；选择依据是投资范围，不向模型提供回测收益或候选分数。指数来自 CSMAR 现有目录，需覆盖评价区间；价格指数只作市场参照，指数收益基准使用全收益口径。缺数或验证失败时停止，不切换数据源。

指数日行情在服务运行期间于交易日 18:30 更新，回查近 10 日；每 90 天回查近 90 日，每年核查完整历史。指数目录每 30 天更新完整快照，计划可在数据同步页面查看，启停和执行时间配置在 `config/benchmark_data.yaml`。这些规则参考 [CFA 基准选择原则](https://www.cfainstitute.org/sites/default/files/-/media/documents/book/rf-publication/2017/rf-v2017-n3-1.pdf)与 [GIPS 基准指引](https://www.gipsstandards.org/wp-content/uploads/2023/08/gs_benchmarks_firms.pdf)。

回测任务通过 Spark 读取 DWD 行情、DWS 因子与历史权重，再由 Python 按交易日顺序执行撮合和账户核算。结果经 Spark 发布到 Hive 的 ADS 表，同步后供页面查看。

### 4.7 账户持仓与策略选股

「账户持仓」按账户展示资金和持仓。选择已启用策略后，点击「获取选股建议」，即可查看建议股票、持仓数量和目标仓位。页面保留账户创建、修改、现金调整和删除，以及手动录入持仓、录入成交和查看交易记录。

创建账户需填写账户名称（必填）、券商和备注，内部编号由系统生成。“已开通科创板权限”默认不勾选，已有账户也默认未开通，可在账户卡片中修改。权限变更后需要重新生成交易计划。条件选股可选择账户，未开通权限时不显示科创板股票。

每个账户分别按持仓、可卖数量、可用现金、资金规模和权限生成建议，并检查最低买入单位、费用与现金保留要求。无权限账户不会收到科创板买入建议，已有科创板持仓仍计入资产并按可卖数量处理。

目标组合控制单票、行业、风格簇集中度和现金比例，并根据市场广度调整仓位。组合批次通过 Spark 读取因子、权重及 KMeans 风格簇，调用 Python 组合构建逻辑，将策略信号和目标持仓发布到 ADS，并写入 HBase 快照。

持仓和现金可单独调整，录入成交会自动更新两者并计算税费。买入股票下一交易日可卖，支持撤回上一笔交易。

### 4.8 AI 研究助手

顶栏的研究助手支持围绕个股、因子和回测结果提问。回答会关联所用模型和证据记录，用户可以展开查看原始依据。

模型接口、密钥和任务路由在「设置 → 模型配置」中管理。配置模型后，可使用自然语言选股、研究助手，以及因子和策略的 AI 研究功能。

### 4.9 任务、集群与研究记录

「设置 → 任务」按时间查看任务进度、日志和错误信息。「设置 → 集群」可启动或停止集群、查看服务健康状态，并进入 HDFS、YARN、HBase 与 Spark History 管理页面。

AI 生成的新因子直接登记到「因子研究 → 因子库」，以草稿状态进入因子实验。因子和策略的研究过程、版本、评价结果及审批记录在各自的研究页面查看。

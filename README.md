# QuantLens · 量镜

## 1. 简要介绍

QuantLens 是面向 A 股日频研究的本地工作台，将数据更新、行情查看、因子与模型实验、股票筛选、预测跟踪和账户管理放在同一套浏览器界面中。

项目涉及的大数据处理技术包括 **Apache Spark、Spark SQL、MLlib 和 Parquet 列式存储**：Spark 负责批量特征计算和模型训练，MLlib 提供机器学习流水线，Parquet 保存行情、特征及预测结果。行情分析和条件查询使用 DuckDB，财务整理与因子矩阵处理使用 Pandas、NumPy。

## 2. 安装方式

### 环境准备

运行环境为 Linux、Python 3.12、OpenJDK 21，Python 需安装 `venv` 组件。

获取源码后，进入项目目录安装依赖：

```bash
cd QuantLens
python3.12 -m venv ~/.venv
~/.venv/bin/python -m pip install -r requirements.txt
```

### 数据与模型配置

- **行情数据**：在“数据中心”页面发起同步。下载需要有效的 CSMAR 数据访问权限，以及校园网或相应 VPN 环境。首次同步会按表补齐历史数据，后续同步按更新计划执行。
- **语言模型**：在“接口配置”页面填写服务地址、模型名称和凭据，供研究助手、自然语言选股和因子、策略生成使用。
- **本地目录**：首次启动会建立运行目录。`data/` 保存数据与计算缓存，`runs/` 保存实验结果和日志，`experience/` 保存研究与任务记录，`portfolio/` 保存账户数据。这些目录及本机凭据由 `.gitignore` 排除。

## 3. 启动方式

在项目目录运行：

```bash
~/.venv/bin/python main.py
```

启动后会自动打开浏览器，地址为 <http://127.0.0.1:8610>。
## 4. 功能介绍

### 4.1 工作台与市场观察

工作台汇总数据覆盖范围、近期研究和运行任务。市场观察展示涨跌分布、市场广度和收益变化，便于先了解整体行情，再进入个股或模型研究。

这部分通过 DuckDB 查询 Parquet 行情表，完成按交易日的筛选和聚合。

选项卡支持预加载与页面缓存，切换时保留已加载内容与输入。

### 4.2 数据同步与更新计划

数据同步覆盖日行情、收益、财务报表、披露日期、行业分类、股东持仓和分析师数据。下载按日期分批进行，写入时按业务主键合并；已有记录发生修订时更新对应值，内容相同的记录直接复用。

日行情和日收益的增量日期一致、且各自只需一个批次时，共用一次下载，再分别入库。各类数据采用不同的检查周期：

| 数据类别 | 常规检查周期 | 每次检查范围 |
| --- | --- | --- |
| 日行情、日收益 | 按可用交易日补齐 | 已完成日期之后的缺失区间 |
| 分析师预测、评级、目标价 | 每 7 天 | 最近 45 天 |
| 财务报表、披露日期 | 每 7 天 | 最近 270 天 |
| 股东及机构持仓 | 每 14 天 | 最近 270 天 |
| 行业分类 | 每 30 天 | 最近 90 天 |

周期从上次成功完成检查时计算，在手动同步或定时跟踪触发时判断是否到期。财务、持仓和分析师表每 90 天回查最近两年，行业分类每 180 天回查最近一年；这些表每 365 天执行一次全历史核查。回查用于补入迟报数据和历史修订，数据页可查看各表的检查计划。

数据以 Parquet 列式文件保存。同步后按源表变化更新派生表和因子矩阵缓存，内容一致的文件与有效缓存继续复用。

### 4.3 股票档案与条件选股

股票档案集中展示 K 线、成交量、财务、行业、机构持仓及已有模型信号。可以记录关注依据和失效条件，将股票加入观察列表。

条件选股支持技术与财务条件组合，也可以通过语言模型将自然语言转换为筛选条件，核对后执行。财务查询按指定日期匹配已披露信息，排除估算公告日；历史更正的可追溯范围取决于源数据保留的版本。

个股查询和批量筛选通过 DuckDB 直接读取 Parquet 表，按证券、日期及条件取数。

### 4.4 因子与策略研究

从研究想法出发，生成或编写因子代码，查看评价结果，再把因子组合成策略。研究过程保留候选版本、实验记录、评审意见与历史证据，便于比较每次修改的依据和结果。

因子矩阵通过 Pandas、NumPy 构建，并以 Parquet 缓存供后续实验复用。因子代码在当前用户权限下执行，运行前应审查代码来源与内容。

### 4.5 模型训练与年度滚动验证

模型研究提供 30 项价量因子，按训练期的相关性、方向稳定性和因子间相关程度进行筛选，再训练梯度提升树回归模型。实验可设置训练、验证、评估区间，以及股票范围、计算核心数和树模型参数。

特征计算使用 **Spark SQL 的关联、分组和窗口运算**；训练使用 **MLlib 的缺失值填补、特征向量组装与 GBT 回归流水线**。Spark 可在本地模式或 Master / Worker 模式下执行这些任务。中间特征、模型预测及相关结果以 Parquet 保存。

年度滚动验证按设定年份逐轮训练和评估，汇总各年度表现。实验详情展示入选因子、重要性、评价指标和交易模拟结果，并支持导出 JSON、打印为 PDF。

训练和验证样本的标签分别限定在各自截止日期内，误差区间使用验证期残差校准。实验保存数据依据、参数和运行结果；评估结果开封后，继续研究会使用新的实验记录。

### 4.6 预测跟踪与组合测算

使用已训练模型生成指定日期的全市场预测，查看股票排名、预测区间，以及个股所用因子的数值、市场分位和模型重要性。批量推理通过 Spark 加载已保存的 MLlib 模型执行。

预测记录区分历史重放与盘后跟踪。收益观察期结束后，系统补齐实际收益并累计排序能力指标。可设置每日运行时间，依次完成数据同步、预测和到期收益更新；该定时功能由用户启用。

组合测算根据预测排名、资金规模、单票权重上限和现金保留比例计算参考持仓，结果单独保存供研究使用。

### 4.7 回测与结果比较

回测页面查看收益、回撤、交易与因子表现，并将结果关联到对应实验和策略版本。

模型页的交易模拟采用次日收盘成交、五日调仓、买入按 100 股取整和用户设置的综合成本。一字价格日采用保守的交易限制，缺失行情时保留持仓末值。模拟结果用于比较研究方案，实际成交效果还取决于流动性、滑点及具体执行条件。

### 4.8 账户、持仓与成交管理

支持账户创建、现金设置、成交录入、持仓查看、交易计划与复盘。单笔成交会检查资金、交易顺序和可卖数量，并同步更新现金与持仓。重复提交通过请求标识识别，写入异常由事务恢复机制处理。

批量导入与审计补丁用于整理成交记录，现金调整通过账户操作单独完成。

### 4.9 研究助手与研究时间线

研究助手结合行情、财务和研究记录回答问题，并保存对应证据。研究时间线汇总观察依据、提问与研究过程，方便回看当时的判断。

模型解读与原始证据分别展示，便于核对回答依据。

### 4.10 系统维护与计算节点

“系统维护”显示后台任务进度、运行日志和错误信息，支持数据质量检查、缓存重建及计算节点管理。

Master 负责协调 Spark 应用资源，Worker 提供执行资源，History Server 展示已结束应用的执行记录。当前两个 Worker 运行在同一台机器上，可用于观察任务分配、分区计算与执行过程。较小的实验可直接使用 Spark 本地模式。
